# Repo for testing NeuroFL modeler setup

The short version
1. Open the Modeler UI and log in (your access is set up by an admin; see Quick start).
2. Open Submit Model Package and pick the datasets you want to train on.
3. Choose Simple mode and provide just your shared.py (model + data logic) plus a few
settings. The platform builds everything else for you.
4. Submit. Your run is reviewed by an admin, then trains; you watch its status and
download metrics/weights in the UI.
